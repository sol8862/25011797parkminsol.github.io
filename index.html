PDF 저장 방법

PC에서 저장하기

  1. 화면의 인쇄 · PDF 버튼을 누릅니다.
  2. 인쇄 창의 프린터 또는 대상을 PDF로 저장으로 선택합니다.
    Windows는 Microsoft Print to PDF, Mac은 왼쪽 아래 PDF → PDF로 저장을 선택하면 됩니다.
  3. 페이지와 방향을 확인한 뒤 저장을 누르고 파일 이름과 위치를 정합니다.

아이폰에서 저장하기

  1. 화면의 인쇄 · PDF 버튼을 누릅니다.
  2. 인쇄 미리보기가 나오면 미리보기 문서를 두 손가락으로 벌려 PDF 화면으로 엽니다.
  3. 오른쪽 아래 또는 위의 공유 버튼(□↑)을 누릅니다.
  4. 파일에 저장 → 저장할 폴더 → 저장을 누릅니다.

PDF 미리보기 화면이 이미 열려 있다면 공유 버튼을 누른 뒤 ‘파일에 저장’을 선택하세요.

갤럭시에서 저장하기

  1. 화면의 인쇄 · PDF 버튼을 누릅니다.
  2. 인쇄 화면 위쪽의 프린터 선택 메뉴를 눌러 PDF로 저장을 선택합니다.
  3. 페이지와 용지 크기를 확인한 뒤 PDF 저장 아이콘을 누릅니다.
  4. 파일 이름과 저장 위치를 정하고 저장을 누릅니다.

기종에 따라 버튼 이름이 ‘PDF로 저장’ 또는 ‘파일로 저장’으로 표시될 수 있습니다.
